# API and data-format learning examples

These files illustrate the shape of employee data in JSON and XML, plus a generic SOAP envelope. They are educational examples only. There is no live REST server, no Workday endpoint, no Workday credentials, and no actual Workday API integration in this repository.

Study points:
- JSON is commonly used with REST APIs.
- XML is a markup format used in many enterprise integrations.
- SOAP messages use an XML envelope and typically follow a formal service contract.
- Real integrations require approved endpoints, authentication, schema validation, logging, and secure handling of personal data.
